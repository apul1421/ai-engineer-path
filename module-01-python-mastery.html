01 Advanced Functions

Functions as First-Class Objects

In Python, functions are objects. You can pass them as arguments, return them from other functions, and store them in data structures. This is the foundation of decorators, callbacks, and every AI framework's plugin system.

Lambda, map, filter, sorted functional tools

Lambdas are anonymous one-liners. map and filter apply functions lazily to iterables. In AI code they appear constantly in data preprocessing pipelines.

lambda_map_filter.pyPython
# Lambda: anonymous one-expression function
to_lower  = lambda s: s.lower().strip()
clamp     = lambda x, lo, hi: max(lo, min(hi, x))

# map — lazy iterator; wrap in list() to evaluate
raw   = ["  Hello World  ", "  RAG Systems  ", "LangChain "]
clean = list(map(to_lower, raw))          # ['hello world', 'rag systems', 'langchain']

# filter — keep elements where predicate is True
scores    = [0.91, 0.43, 0.88, 0.31, 0.76]
high_conf = list(filter(lambda s: s > 0.75, scores))    # [0.91, 0.88, 0.76]

# sorted with key — rank retrieved chunks by relevance
chunks   = [("doc_a", 0.82), ("doc_b", 0.91), ("doc_c", 0.77)]
top_docs = sorted(chunks, key=lambda d: d[1], reverse=True)
# [('doc_b', 0.91), ('doc_a', 0.82), ('doc_c', 0.77)]

# Prefer list comprehensions for readability in most cases
high_conf2 = [s for s in scores if s > 0.75]   # same result, clearer

Closures — state without classes factory pattern

A closure is a function that captures variables from its enclosing scope. This creates stateful functions without a full class — used in factory patterns, middleware, and pre-configured model callers.

closures.pyPython
# Closure: 'threshold' is captured from the outer scope
def make_threshold_filter(threshold: float):
    def filter_fn(score: float) -> bool:
        return score >= threshold   # threshold is closed over
    return filter_fn               # return the function itself

high_quality   = make_threshold_filter(0.85)
medium_quality = make_threshold_filter(0.65)

results = [0.91, 0.70, 0.55, 0.88]
print([r for r in results if high_quality(r)])     # [0.91, 0.88]
print([r for r in results if medium_quality(r)])   # [0.91, 0.70, 0.88]

# Real AI use: pre-configured model callers per provider
def make_model_caller(model_name: str, temperature: float = 0.7):
    def call(prompt: str) -> str:
        return llm.complete(prompt, model=model_name, temp=temperature)
    return call

creative_claude = make_model_caller("claude-sonnet-4-6", temperature=1.0)
precise_gpt     = make_model_caller("gpt-4o",           temperature=0.0)

# *args and **kwargs — accept any positional/keyword arguments
def log_and_call(func, *args, **kwargs):
    print(f"Calling {func.__name__} with {args}, {kwargs}")
    return func(*args, **kwargs)

02 Generators & Iterators

Memory-Efficient Data Pipelines

The single most important concept for AI data engineering. A generator processes one item at a time — constant memory regardless of dataset size. Every production ML pipeline: PyTorch DataLoader, HuggingFace datasets, LangChain document loaders — is built on this pattern.

Generator functions with yield lazy evaluation

generators.pyPython
import json
from typing import Generator, Iterator

# Generator function: reads one line at a time, never loads full file
def stream_jsonl(filepath: str) -> Generator[dict, None, None]:
    with open(filepath) as f:
        for line in f:
            if line.strip():
                yield json.loads(line)    # suspend; caller gets value; then resume

# Chained generators — compose a lazy pipeline
def clean_docs(docs: Iterator[dict]) -> Generator[dict, None, None]:
    for doc in docs:
        doc["text"] = doc["text"].strip().lower()
        if len(doc["text"]) > 50:
            yield doc

def chunk_docs(docs: Iterator[dict], size: int = 512) -> Generator[dict, None, None]:
    for doc in docs:
        words = doc["text"].split()
        for i in range(0, len(words), size):
            yield {**doc, "chunk": " ".join(words[i:i+size]), "idx": i // size}

# Compose the pipeline — nothing executes until you iterate
raw    = stream_jsonl("corpus.jsonl")   # generator: lazy file read
clean  = clean_docs(raw)                # generator: lazy filter+clean
chunks = chunk_docs(clean)              # generator: lazy chunking

for chunk in chunks:
    embed_and_store(chunk)   # ONE chunk processed at a time: O(1) memory for 10GB corpus

# Generator expression — concise one-liner generators
token_lengths = (len(tokenise(doc["text"])) for doc in raw_docs)
avg_tokens    = sum(token_lengths) / total_docs   # computed lazily
💡
Production rule: Any function reading from disk, calling an API in a loop, or processing large datasets should return a generator — never a list. PyTorch DataLoader, HuggingFace datasets streaming, every RAG document loader in Module 07 uses this pattern. Memory savings: gigabytes → kilobytes.

The iterator protocol __iter__ and __next__

custom_iterator.pyPython
# Custom iterator: sliding window over a token stream
class TokenWindow:
    def __init__(self, tokens: list[int], window: int, stride: int):
        self.tokens = tokens
        self.window = window
        self.stride = stride
        self._pos   = 0

    def __iter__(self):   # called by for loop — return self for stateful iteration
        self._pos = 0
        return self

    def __next__(self):   # called each iteration; raise StopIteration when done
        if self._pos >= len(self.tokens):
            raise StopIteration
        chunk      = self.tokens[self._pos : self._pos + self.window]
        self._pos += self.stride
        return chunk

tokens = list(range(20))
for window in TokenWindow(tokens, window=5, stride=3):
    print(window)   # [0,1,2,3,4]  [3,4,5,6,7]  [6,7,8,9,10] ...
03 Decorators

Decorators — Cross-Cutting Concerns

A decorator wraps a function to add behaviour without modifying its code. This is how you add retry logic, caching, rate-limiting, and logging to AI API calls — once, cleanly, and reusably across your entire codebase.

production_decorators.pyPython
import functools, time, logging
from typing import Callable, TypeVar
F = TypeVar('F', bound=Callable)

# 1. Retry with exponential backoff — essential for every LLM API call
def retry(max_attempts: int = 3, exceptions: tuple = (Exception,)):
    def decorator(func: F) -> F:
        @functools.wraps(func)   # preserves __name__, __doc__ — ALWAYS include this
        def wrapper(*args, **kwargs):
            for attempt in range(1, max_attempts + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    if attempt == max_attempts: raise
                    wait = 2 ** attempt
                    logging.warning(f"Attempt {attempt} failed ({e}), retrying in {wait}s")
                    time.sleep(wait)
        return wrapper  # type: ignore
    return decorator

# 2. TTL cache — avoid re-computing identical embeddings
def cache_ttl(seconds: int = 300):
    def decorator(func: F) -> F:
        _cache: dict = {}
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            key = (args, tuple(sorted(kwargs.items())))
            if key in _cache:
                val, ts = _cache[key]
                if time.time() - ts < seconds: return val
            result = func(*args, **kwargs)
            _cache[key] = (result, time.time())
            return result
        return wrapper  # type: ignore
    return decorator

# 3. Rate limiter — respect provider limits (e.g. 60 req/min on free tier)
def rate_limit(calls_per_minute: int):
    min_gap    = 60.0 / calls_per_minute
    last_call  = [0.0]   # list so closure can mutate it
    def decorator(func: F) -> F:
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            gap = time.time() - last_call[0]
            if gap < min_gap: time.sleep(min_gap - gap)
            last_call[0] = time.time()
            return func(*args, **kwargs)
        return wrapper  # type: ignore
    return decorator

# Stack decorators — applied bottom-up, outermost runs first
@retry(max_attempts=4, exceptions=(ConnectionError, TimeoutError))
@rate_limit(60)
@cache_ttl(600)
def get_embedding(text: str) -> list[float]:
    return openai.embeddings.create(input=text).data[0].embedding
# Execution: check cache → rate limit → retry on failure → API call
🔑
Always use @functools.wraps(func). Without it, your wrapper replaces the decorated function's __name__, __doc__, and __module__. This breaks FastAPI route identification, stack traces, logging, and documentation tools. It's one line — no excuse to skip it.
04 Context Managers

Context Managers & Resource Safety

Context managers guarantee cleanup — files close, connections release, GPU memory frees — even when exceptions occur. In AI systems this means database connections, model sessions, GPU memory, and transaction scopes.

context_managers.pyPython
from contextlib import contextmanager, asynccontextmanager
import time, logging

# Method 1: Class with __enter__ / __exit__
class ModelSession:
    '''Loads model to GPU on enter, frees memory on exit.'''
    def __init__(self, model_name: str):
        self.model_name = model_name

    def __enter__(self):
        self.model = load_model(self.model_name)
        return self.model         # bound to 'as model'

    def __exit__(self, exc_type, exc_val, exc_tb):
        del self.model             # runs even if exception raised inside with block
        return False              # False = don't suppress the exception

with ModelSession("llama-3-8b") as model:
    embeddings = model.encode(texts)   # GPU freed when block exits, error or not

# Method 2: @contextmanager — cleaner for simple one-shot resources
@contextmanager
def timer(label: str):
    start = time.perf_counter()
    try:
        yield                           # execution enters the 'with' block here
    finally:                            # always runs — exception or not
        logging.info(f"[{label}] {time.perf_counter()-start:.3f}s")

with timer("embedding batch"):
    embeddings = model.encode(texts)

# Method 3: Async context manager — for async database transactions
@asynccontextmanager
async def db_transaction(pool):
    conn = await pool.acquire()
    tx   = await conn.transaction()
    try:
        yield conn
        await tx.commit()
    except Exception:
        await tx.rollback()            # always rollback on any error
        raise
    finally:
        await pool.release(conn)

async with db_transaction(pg_pool) as conn:
    await conn.execute("INSERT INTO embeddings VALUES ($1, $2)", doc_id, vec)
05 Functional Programming

Functional Patterns in AI Pipelines

Functional programming treats computation as pure functions — no side effects, immutable data. This style composes naturally and is trivially testable. AI preprocessing pipelines are almost always written this way.

functional.pyPython
from functools import reduce, partial, lru_cache
from typing import Callable

# partial — pre-fill arguments; creates a new callable
def chunk_text(text: str, size: int, overlap: int) -> list[str]: ...

chunk_512  = partial(chunk_text, size=512,  overlap=50)
chunk_1024 = partial(chunk_text, size=1024, overlap=100)

# reduce — fold a sequence to a single value
configs = [{"temp": 0.7}, {"top_p": 0.9}, {"max_tokens": 1024}]
merged  = reduce(lambda a, b: {**a, **b}, configs)
# {"temp": 0.7, "top_p": 0.9, "max_tokens": 1024}

# @lru_cache — memoize pure functions; O(1) on repeated calls
@lru_cache(maxsize=10_000)
def tokenise(text: str) -> tuple[int, ...]:   # args must be hashable
    return tuple(tokeniser.encode(text))

# Function composition — build preprocessing pipelines declaratively
def compose(*fns: Callable) -> Callable:
    '''compose(f, g, h)(x)  ==  h(g(f(x)))  -- left to right'''
    return lambda x: reduce(lambda v, f: f(v), fns, x)

preprocess = compose(
    lambda t: t.lower(),
    lambda t: t.strip(),
    lambda t: " ".join(t.split()),     # collapse whitespace
    lambda t: t.replace("\n", " "),
)
clean = preprocess("  Hello\n  World  ")   # "hello world"

# Immutable data with namedtuple / dataclass(frozen=True)
from dataclasses import dataclass

@dataclass(frozen=True)   # immutable; hashable; safe in caches
class Chunk:
    doc_id: str
    text:   str
    index:  int
06 Async & Concurrency

Async Python — The AI Superpower

LLM API calls take 1–30 seconds each. Processed sequentially, 1,000 documents takes hours. With asyncio, all requests run concurrently. This is the single biggest performance lever in AI engineering.

Choose the right model decision table

ModelBest ForBypasses GIL?AI Use Case
asyncioI/O-bound: API calls, DB queries, file readsNot neededCalling LLM/embedding APIs; streaming RAG responses
threadingI/O-bound with legacy sync codeNoWrapping sync SDK in a threaded FastAPI server
multiprocessingCPU-bound: tokenisation, preprocessingYesParallel document preprocessing; CPU model inference
async_ai.pyPython
import asyncio
from anthropic import AsyncAnthropic

client = AsyncAnthropic()

# Basic async function
async def summarise(doc: str, doc_id: str) -> dict:
    response = await client.messages.create(
        model="claude-sonnet-4-6", max_tokens=256,
        messages=[{"role": "user", "content": f"Summarise in 3 sentences:\n{doc}"}]
    )
    return {"id": doc_id, "summary": response.content[0].text}

# Semaphore — cap concurrent API calls to respect rate limits
async def batch_summarise(docs: list[dict], max_concurrent: int = 10) -> list[dict]:
    sem = asyncio.Semaphore(max_concurrent)

    async def limited(doc: dict) -> dict:
        async with sem:             # at most 10 concurrent API calls
            return await summarise(doc["text"], doc["id"])

    return await asyncio.gather(
        *[limited(d) for d in docs],
        return_exceptions=True    # one failure doesn't cancel all others
    )

# Streaming — yield tokens as they arrive (used in RAG APIs)
async def stream_answer(prompt: str):
    async with client.messages.stream(
        model="claude-sonnet-4-6", max_tokens=1024,
        messages=[{"role": "user", "content": prompt}]
    ) as stream:
        async for token in stream.text_stream:
            print(token, end="", flush=True)   # real-time output

# asyncio.Queue — producer/consumer pattern for large batches
async def pipeline(paths: list[str], workers: int = 5):
    queue: asyncio.Queue = asyncio.Queue(maxsize=50)

    async def producer():
        for p in paths: await queue.put(p)
        for _ in range(workers): await queue.put(None)   # sentinels

    async def worker():
        while True:
            path = await queue.get()
            if path is None: break
            await process_document(path)
            queue.task_done()

    await asyncio.gather(producer(), *[worker() for _ in range(workers)])

# True CPU parallelism: ProcessPoolExecutor bypasses the GIL
from concurrent.futures import ProcessPoolExecutor
from multiprocessing import cpu_count

def tokenise_doc(text: str) -> list[int]:
    return tokeniser.encode(text)   # CPU-heavy; runs in separate process

with ProcessPoolExecutor(max_workers=cpu_count()) as pool:
    all_tokens = list(pool.map(tokenise_doc, texts))   # 8x on 8-core machine
07 Pydantic v2

Pydantic v2 — Data That Can't Lie

Pydantic enforces data contracts at runtime. In AI systems where LLMs return JSON, users send requests, and agents pass state between each other — invalid data causes silent bugs at 3am. Pydantic is your first line of defence.

temperaturefloat0.0 ≤ value ≤ 2.0, default 0.7optional

pydantic_ai.pyPython
from pydantic import BaseModel, Field, field_validator, model_validator, ConfigDict
from typing import Literal, Optional, Annotated
from enum import Enum

class ModelChoice(str, Enum):
    GPT4O      = "gpt-4o"
    CLAUDE     = "claude-sonnet-4-6"
    CLAUDE_OPS = "claude-opus-4-6"

class Message(BaseModel):
    role:    Literal["user", "assistant", "system"]
    content: Annotated[str, Field(min_length=1, max_length=200_000)]

class LLMRequest(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True, use_enum_values=True)

    model:       ModelChoice
    messages:    Annotated[list[Message], Field(min_length=1)]
    temperature: float         = Field(default=0.7, ge=0.0, le=2.0)
    max_tokens:  Optional[int] = Field(default=None, ge=1, le=128_000)
    stream:      bool          = False
    metadata:    dict[str, str] = Field(default_factory=dict)

    # @field_validator: runs on a single field after type coercion
    @field_validator("messages")
    @classmethod
    def last_must_be_user(cls, v: list[Message]) -> list[Message]:
        if v[-1].role != "user":
            raise ValueError("Last message must have role='user'")
        return v

    # @model_validator(mode="after"): runs after ALL fields validated; cross-field rules
    @model_validator(mode="after")
    def stream_and_max_tokens(self) -> "LLMRequest":
        if self.stream and self.max_tokens is not None:
            raise ValueError("max_tokens must be None when streaming")
        return self

# Usage
req = LLMRequest(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "Explain RAG"}],
    temperature=0.9
)
payload = req.model_dump_json(indent=2)   # v2 API — not .json()
raw     = req.model_dump()                   # dict — not .dict()
⚠️
Pydantic v1 vs v2 — breaking changes: @validator → @field_validator • .dict() → .model_dump() • .json() → .model_dump_json(). Most tutorials on the internet are v1. Always check pydantic.__version__ and read the v2 migration guide.
08 Enterprise Patterns

Enterprise Python — Logging, Config, Exceptions

The gap between a working prototype and production code is almost entirely these patterns. Structured logging, environment-based config, and domain exceptions are table stakes at any serious AI company.

enterprise_patterns.pyPython
# 1. Structured JSON logging — parseable by DataDog, CloudWatch, Loki
import logging, json, sys
from datetime import datetime, timezone

class JSONFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        return json.dumps({
            "ts":    datetime.now(timezone.utc).isoformat(),
            "level": record.levelname,
            "msg":   record.getMessage(),
            "mod":   record.module,
            "line":  record.lineno,
        })

def setup_logging(level: str = "INFO") -> None:
    h = logging.StreamHandler(sys.stdout)
    h.setFormatter(JSONFormatter())
    logging.basicConfig(level=level, handlers=[h], force=True)

# 2. Config management with Pydantic Settings (reads from .env + env vars)
from pydantic_settings import BaseSettings
from pydantic import Field
from functools import lru_cache

class Settings(BaseSettings):
    openai_api_key:    str = Field(alias="OPENAI_API_KEY")
    anthropic_api_key: str = Field(alias="ANTHROPIC_API_KEY")
    database_url:      str = Field(alias="DATABASE_URL")
    redis_url:         str = "redis://localhost:6379"
    max_concurrent:    int = 10
    model_config = {"env_file": ".env"}

@lru_cache()                   # load once, reuse everywhere
def get_settings() -> Settings:
    return Settings()          # NEVER hardcode credentials

# 3. Custom domain exceptions — granular error handling
class AIError(Exception): '''Base for all AI pipeline errors.'''

class TokenLimitExceeded(AIError):
    def __init__(self, count: int, limit: int):
        self.count, self.limit = count, limit
        super().__init__(f"Prompt has {count} tokens; limit is {limit}")

class ModelUnavailableError(AIError): pass

def safe_complete(prompt: str) -> str | None:
    try:
        return llm.complete(prompt)
    except TokenLimitExceeded as e:
        logging.warning(f"Trimming prompt from {e.count} to {e.limit} tokens")
        return llm.complete(trim_to_limit(prompt, e.limit))
    except ModelUnavailableError:
        return fallback_llm.complete(prompt)   # graceful degradation
    except Exception as e:
        logging.error(f"Unexpected error: {e}", exc_info=True)
        return None
09 Testing

Testing AI Code — The Right Way

Untested AI code is a liability. Testing LLM-dependent code is tricky — you can't call the real API in CI. The answer: mock dependencies, test pure logic in isolation, and keep I/O-heavy code thin.

test_pipeline.pyPython
import pytest
from unittest.mock import MagicMock, AsyncMock
from my_rag.chunker  import chunk_document
from my_rag.pipeline import RAGPipeline

# Pure functions: no mocking needed — just call and assert
class TestChunker:
    def test_chunks_long_doc(self):
        text = " ".join(["word"] * 600)
        assert len(chunk_document(text, chunk_size=512, overlap=50)) == 2

    def test_empty_input_returns_empty(self):
        assert chunk_document("") == []

    def test_overlap_shared_tokens(self):
        text   = " ".join(str(i) for i in range(100))
        chunks = chunk_document(text, chunk_size=50, overlap=10)
        assert chunks[0].split()[-10:] == chunks[1].split()[:10]
